# MCP Guides

Setup guides for the MCP (Model Context Protocol) servers that the Ace OS agents can use.

| Guide | Used By | Required? |
|-------|---------|-----------|
| [prerequisites.md](prerequisites.md) | All MCP servers | Read first |
| [google-workspace.md](google-workspace.md) | `calendar-audit` | Optional — only if you want calendar features |

The `start-here` agent walks you through MCP setup based on which agents you keep active. You can run any of these guides on your own at any time.
