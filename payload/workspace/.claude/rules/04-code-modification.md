# Code Modification Policy

**CRITICAL:** Never modify code without explicit permission from the user.

- **Never change working code** unless explicitly asked to do so
- **Always ask before modifying** - explain what you want to change and why
- **Prioritize understanding over "improving"** - when restoring a working system, help get back to what worked, don't "optimize" without permission
- **Especially important when** the user is trying to restore a previously working setup after a reinstall or issue
