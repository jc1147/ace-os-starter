# Tasks Inbox

Open list of actionable work that isn't yet attached to a project, initiative, or KR. Add anything here when you don't yet know where it belongs — `start-here` and `goals-onboarding` will sort it later.

## Format

```markdown
- [ ] {Task description} — {context, link, or owner if known} — added {YYYY-MM-DD}
```

Mark items done by changing `[ ]` to `[x]`. Move stale items to `goals/maintenance-tasks.md` for cleanup.
