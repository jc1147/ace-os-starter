On "wrap up", deliver the closing summary (what shipped, what is uncommitted, what is still open) and stop there.
Open items are stated as plain facts, not as questions. Commit only when asked.

**Why:** "wrap up" means the person is closing the session, not asking for more work. Trailing offers add friction:
they have to read and wave each one off.

**How to apply:** end at the state summary. The sanctioned way to point at next steps is a current resume doc with a
kickstart line ([[feedback_wrap_leaves_resume_doc_and_kickstart]]), not an offer. In a mid-session checkpoint, keep
working on the next instruction instead ([[feedback_wrap_up_mid_session_is_a_checkpoint]]).
